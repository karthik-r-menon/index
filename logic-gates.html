// 06 · THEORY

Boolean Laws

Fundamental theorems and laws governing Boolean algebra and digital logic design.

⟳ IDENTITY LAWS

A + 0 = A
A · 1 = A

Adding 0 or multiplying by 1 has no effect on the variable. The identity elements for OR is 0, for AND is 1.

// Example: A + 0 = A (if A=1, output=1)

⬤ NULL / ANNIHILATION LAWS

A + 1 = 1
A · 0 = 0

OR with 1 always gives 1. AND with 0 always gives 0 — regardless of other inputs.

// Example: A · 0 = 0 always (dominant element)

≡ IDEMPOTENT LAWS

A + A = A
A · A = A

A variable OR'd or AND'd with itself returns itself. No new information is gained from repetition.

// Example: 1+1=1, 0+0=0

⊥ COMPLEMENT LAWS

A + Ā = 1
A · Ā = 0

A variable OR'd with its complement is always 1. AND with complement is always 0.

// Example: A=1, Ā=0 → 1+0=1, 1·0=0

↻ INVOLUTION (DOUBLE NOT)

Ā̄ = A

Inverting a variable twice returns the original value. Two NOT gates in series cancel each other.

// Example: NOT(NOT(A)) = A

⇄ COMMUTATIVE LAWS

A + B = B + A
A · B = B · A

The order of inputs does not affect the output of OR or AND gates.

// Example: A·B = B·A (gate output same)

⟨⟩ ASSOCIATIVE LAWS

A+(B+C) = (A+B)+C
A·(B·C) = (A·B)·C

Grouping of variables doesn't affect the result in chained AND or OR operations.

// Parentheses can be regrouped freely

⊞ DISTRIBUTIVE LAWS

A·(B+C) = AB+AC
A+(B·C) = (A+B)·(A+C)

AND distributes over OR, and OR distributes over AND — unlike ordinary algebra where only one distributes.

// Essential for SOP/POS form conversion

⊗ DE MORGAN'S THEOREM 1

(A · B)̄ = Ā + B̄

The complement of a product equals the sum of the complements. NAND gate ≡ bubbled OR gate.

// NAND(A,B) = NOT-A OR NOT-B

◈ ABSORPTION LAWS

A + AB = A
A · (A + B) = A

The redundant term AB is absorbed by A. Essential for Karnaugh map simplification.

// Eliminates redundant terms in SOP

⬡ CONSENSUS THEOREM

AB + ĀC + BC = AB + ĀC

The consensus term BC is redundant and can be removed. Advanced simplification technique.

// BC is covered by AB or ĀC for all cases
